# Go Café

Sistema web para la gestión de una planta de procesamiento de café.

Permite registrar a los clientes y sus órdenes de procesamiento (recepción, trillado, tueste, molienda y empaque), llevar la producción propia, el inventario, los cobros y los gastos del negocio.

Los clientes pueden seguir el avance de su pedido desde el celular con un enlace que se les envía por WhatsApp, y guardar una tarjeta del pedido en Google Wallet que se actualiza sola y les avisa cuando está listo para recoger.

**Tecnologías:** React · TypeScript · Node.js · Express · PostgreSQL
